# Orion Learning Notes

These notes explain Orion's main ideas in plain language.

Each idea has one main note:

- [The robot model](orion_urdf_basics.md): links, joints, frames, shapes, and limits.
- [Orion's joint structure](orion_joints.md): what each powered joint connects and moves.
- [The base frame and RViz grid](base_footprint_and_rviz_grid.md): why the model stands on the grid.
- [ROS control](orion_ros_control.md): how ROS reads joints and sends movement commands.
- [The motion system](orion_motion_system.md): how a named motion becomes a safe command.
- [The MuJoCo model](orion_mujoco_model_basics.md): how Orion is represented in MuJoCo.

Project planning belongs in the guidebook and design documents. These learning
notes only explain concepts and how the system works.
