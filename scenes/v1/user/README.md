# V1 user scenes

Studio publishes user scenes here with `format_version: 2`. User names cannot replace built-ins.

Motion clips cannot overlap. Light and audio tracks can run together. Events use either a time or a marker trigger.

The finish policy uses `final_pose` and `pose_default`. Updates require the loaded content revision. The runtime validates the full catalogue before reload.

See the [scene schema](../../README.md).
