# Studio processing models

Qwen3-ASR, Chatterbox and its tokenizer are downloaded into the Hugging Face
cache by `../.venv/bin/orion-voice-models`. Their weights are not stored here.
Rustpotter's reference belongs to the Pi listener at
`../../../voice/models/wake/hey_orion_reference.rpw`; Studio does not load it.
See [model management](../../../docs/how-to/manage-studio-voice-models.md).
