# Orion Studio design context

## Users

Builders edit poses, motions, lighting, sound and scenes. Owners connect Orion, use voice, select expressions and inspect its state. Studio supports both groups without exposing unnecessary servo details.

## Visual direction

Use a calm, clear workspace for creative work. Keep navy surfaces with restrained blue, cyan and violet accents. Use readable text, clear inspectors and separate tracks. Avoid decorative panels that compete with the task.

## Design rules

- Put expression editing before hardware details.
- Keep selection, preview, editing and playback in one readable flow.
- Show ownership, operation state and errors clearly.
- Keep advanced controls available without filling the default view.
- Meet WCAG AA contrast requirements.
- Preserve keyboard focus.
- Communicate state through more than color.
- Respect reduced-motion preferences.
- Keep essential controls available on smaller screens.

The default appearance is dark. Motion and light previews explain behavior rather than decorate the interface.
